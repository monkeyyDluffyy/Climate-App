🌦️ Climate App – Android Weather & Climate Companion
Climate App is an Android application built using Kotlin and Android Studio that provides users with essential weather and climate information in an intuitive and user-friendly interface. Designed with educational and practical use in mind, the app features:

🌍 Live Climate Data – Displays real-time weather details like temperature, humidity, and more.

📊 Statistical Charts – Visualizes climate trends with charts and graphs for better understanding.

🗺️ Interactive Map – Shows geographical weather patterns or user-selected locations.

ℹ️ About Section – Provides insights into the app and its development.

🎨 Modern UI – Built using best practices in Kotlin and AndroidX for smooth performance and design consistency.

🛠️ Tech Stack
Language: Kotlin

IDE: Android Studio

Libraries: AndroidX, Material Components, Jetpack

Build Tool: Gradle (Kotlin DSL)

🚀 Getting Started
Clone the repository.

Open in Android Studio.

Make sure your local local.properties points to your Android SDK.

Build and run on an emulator or Android device.
